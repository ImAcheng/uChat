# uChat
A decentralized chat app providing extra features.

## Frameworks
* Desktop Application: Windows Form Apps (.NET 9)
* API: ASP.NET Web API (.NET 9)
* Mobile Application: Android API 34, Jetpack Compose, Kotlin

## Apps Included
* API Program (Windows)
* Desktop Application (Windows)
* Mobile Application (Android)

## Features
* Chats
* Create Private Server (SQL Server Required)
* AI Chat
* AI Assistant (Message Summary / Translation)

## Private Server Setup
1. Install SQL Server 2025 Developer Edition (Default Installation)
2. Setup Database & Connection Properties in API GUI Program
3. Create Servers in Desktop Application (Done)
